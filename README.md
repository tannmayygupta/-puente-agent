# Puente

**Send dollars, they receive pesos or reais. An agent does the rest, on Celo mainnet.**

Puente is an autonomous payment agent built for the *Agents on Open Rails* hackathon (Celo). A payer settles in USA₮ (or USD₮ / USDC) over x402, and the agent finds the FX route on Textile, swaps, and delivers local-currency stablecoins (wARS, wBRL, wCOP, wMXN from Ripio) to the recipient.

> Work in progress. Built during the hackathon.

## Tracks
- Stable Agents: LatAm (Ripio wFIAT)
- Open Corridors: Textile FX
- Open Corridors: USA₮ with x402
- Build with buy
